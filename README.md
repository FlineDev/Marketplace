# FlineDev Marketplace

Claude Code plugin marketplace by [FlineDev (Cihat Gündüz)](https://fline.dev).

## Installation

```
/plugin marketplace add FlineDev/Marketplace
```

## Available Plugins

| Plugin | Description |
|--------|-------------|
| [custom-statusline](https://github.com/FlineDev/CustomStatusline) | Real-time usage monitoring statusline showing context window, 5h session, and 7d weekly limits |

## Installing a Plugin

After adding the marketplace, install any plugin with:

```
/plugin install custom-statusline
```
